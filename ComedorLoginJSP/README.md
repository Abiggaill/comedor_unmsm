# Comedor UNMSM: primer check de la etapa 1

Este proyecto contiene solamente la interfaz gráfica del login con JSP y HTML. El botón no inicia sesión todavía. No incluye validación, conexión a la base de datos ni despliegue.

## Para abrirlo en NetBeans
1. Abre NetBeans.
2. Selecciona File > Open Project.
3. Elige la carpeta ComedorLoginJSP.
4. Ejecútalo en un servidor compatible con Jakarta Pages/JSP, por ejemplo Apache Tomcat 10.1.

El proyecto requiere JDK 17 o superior y soporte Maven. La primera ejecución de Maven requiere internet para descargar las dependencias.
